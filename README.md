# Home Library

A phone-first web app for cataloging a personal library. See [handoff.md](handoff.md) for the full plan.

Live at: https://alltherightpills.github.io/home-library/

## Working on it

- `npm install` installs the building blocks (once, or after they change).
- `npm run dev` starts a live preview on your Mac.
- `npm run build` packs the app into the `dist` folder (GitHub does this automatically on every push).
